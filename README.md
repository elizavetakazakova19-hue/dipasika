# dipasika

Коллекция маленьких статических проектов. **Один проект — одна папка в корне.**

## Проекты

| Проект | Папка | Что это |
| --- | --- | --- |
| Открытка для Леры | [`otkrytka-lera/`](otkrytka-lera/) | страница-открытка: нейроптица и менеджерские суперсилы; имя получателя — ссылкой `?name=` или скачанной копией |
| Мем-баттл | [`meme-battle/`](meme-battle/) | онлайн-игра в мемы: комната по коду, голосование с разных телефонов, боты; есть режим на одном устройстве |

## Как устроено

```
.
├── index.html          витрина: карточки со ссылками на проекты
├── README.md           этот файл — оглавление
├── otkrytka-lera/      проект
│   ├── index.html      страница проекта
│   ├── README.md       описание проекта
│   └── previews/       скриншоты
└── meme-battle/        игра
    ├── index.html      онлайн-версия: лендинг и лобби
    ├── local.html      режим на одном телефоне
    ├── online.js       комнаты и синхронизация
    ├── app.js          локальная игра
    ├── data.js         шаблоны мемов
    ├── styles.css      оформление
    ├── README.md       описание проекта
    └── previews/       скриншоты
```

Правила простые:

- корень — только `README.md`, `index.html` (витрина), `.gitignore` и папки проектов;
- ничего не лежит в корне «просто так» — каждый файл живёт в папке своего проекта;
- имя папки — короткий латинский слаг в нижнем регистре через дефис (`otkrytka-lera`, `my-project`);
- у каждого проекта свой `index.html`, свой `README.md` и своя папка `previews/` для скриншотов;
- проекты независимы: без общих зависимостей и сборки, открываются двойным кликом.

## Как добавить новый проект

1. Создать папку: `mkdir my-project`.
2. Положить туда `index.html` (и `README.md`, если нужно описание).
3. Добавить строку в таблицу «Проекты» выше и карточку в корневой `index.html`.

## Просмотр

- локально: открыть `index.html` нужного проекта (или корневой — там ссылки);
- на GitHub Pages: корень репозитория — витрина, `/otkrytka-lera/` и `/meme-battle/` — сами проекты.
