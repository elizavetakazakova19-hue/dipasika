# Открытка для Леры

Статическая страница-открытка: один файл `index.html`, без сборки, без зависимостей и без интернета.

## Как посмотреть

Открыть `index.html` двойным кликом — всё работает локально из файла.

## Имя получателя

Имя стоит в заголовке, в реплике птицы, в счёте внизу и в названии вкладки. В разметку оно не зашито — задаётся в одном месте, в начале `<script>`:

```js
var CARD = {
  name: "Лера"
};
```

Поменять имя можно четырьмя способами:

| Способ | Что сделать | Когда пригодится |
| --- | --- | --- |
| файлом | «сменить имя» → ввести имя → «Скачать копию» | отправить открытку как файл: имя уже вшито внутрь |
| ссылкой | добавить к адресу `?name=Юля` (или `?to=Юля`) | если открытка лежит на хостинге — достаточно отправить другую ссылку |
| кнопкой | «сменить имя» → ввести имя → «Сохранить имя» | примерить имя на текущей странице |
| в коде | поменять `name` в объекте `CARD` | сделать другое имя постоянным |

Имя подставляется как есть, без склонений: «Лера, ты — отличный менеджер», «Юля, ты — …». Поэтому подходит любое имя — Юля, Дима, Дмитрий. Регистр и эмодзи сохраняются, длина ограничена 40 символами; пустое поле возвращает имя из `CARD`.

## Как подарить файлом

Открытка самодостаточна: один HTML-файл, рядом ничего не нужно.

1. Открыть `index.html` двойным кликом.
2. «сменить имя» в подвале → ввести имя, например `Юля`.
3. «Скачать копию» — в папке загрузок появится `otkrytka-Юля.html`, имя уже внутри.
4. Отправить этот файл получателю: он открывается двойным кликом, интернет не нужен.

«Сохранить имя» меняет только текущую страницу и её адрес; отдельный файл делает «Скачать копию».

## Про GitHub Pages

Ссылка вида `https://…/otkrytka-lera/?name=Юля` работает, только если включён Pages. Для приватного репозитория бесплатный GitHub Pages недоступен (`Your current plan does not support GitHub Pages for this repository`); для публичного он включается в Settings → Pages → Deploy from a branch: `main`, `/`.
